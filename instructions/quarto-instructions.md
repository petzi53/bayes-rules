# Quarto Instructions

Use the R language for code chunks.
Use markdown for content.
Create sections with 
::: {#big-text style="font-size: 125%"}
**Text for your heading** 
:::
for main heading and 
::: {#big-text style="font-size: 110%"}
**Text for your subheading** 
:::
for subheadings.
Use `-` for bullet points and `1.` for numbered lists.
Use backticks for inline code and triple backticks for code blocks.
Use `![alt text](image_url)` for images.
Explain all steps of the analysis.
Interpret the results of all analysis and provide insights.
Instead of loading libraries use package name with double colon e..g, `dplyr::mutate()`
Use tidyverse style of coding.
Use ggplot2 for data visualizations.
Use bayesrules and bayesplot packages where appropiate.
Use patchwork for arranging plots.
